## Как сообщить об уязвимости

Если вы нашли уязвимость (SQL-инъекция, обход блокировки, XSS в
панели и т.п.), пожалуйста, **не создавайте публичный Issue** с
подробностями эксплуатации. Опишите проблему через приватный канал
(например, GitHub Security Advisories в этом репозитории) с шагами
воспроизведения.

## Известные ограничения

- `REMOTE_ADDR` используется как источник IP по умолчанию. За
  reverse-proxy/CDN все запросы могут выглядеть идущими с одного IP —
  донастройте `asitee_client_ip()` под ваш `X-Forwarded-For`.
- Инструмент не защищает от распределённого volumetric DDoS с большим
  числом уникальных IP — только от отдельных агрессивных источников.
- Панель управления (`asitee_view.php`) должна быть по возможности
  дополнительно ограничена на уровне веб-сервера (например, по IP
  через `.htaccess` или конфиг nginx).
