# Changelog

## [1.0.0] — 2025

### Добавлено
- Первый публичный релиз.
- Установщик `install.php`: создание таблиц БД, генерация `db.php`,
  `asitee.php`, `asitee_view.php`.
- Rate limiting по IP с настраиваемым порогом и окном времени.
- Ручная блокировка/разблокировка IP через панель.
- Белый список для IP администратора.
- Хеширование пароля администратора (`password_hash`).
- CSRF-защита во всех формах.
