Asitee — это два PHP-файла и своя таблица в MySQL. Никакой магии, никакой
телеметрии, никакого скрытого функционала. Скрипт считает запросы с
каждого IP-адреса и блокирует тех, кто превышает заданный порог, плюс даёт
простую панель для ручного управления блокировками.

## Что это и что не это

**Это:**
- Простой rate-limiter уровня приложения (не сети).
- Инструмент для ручной блокировки надоедливых IP через веб-панель.
- Полностью прозрачный код — вы видите каждую строку перед установкой.

**Это НЕ:**
- ❌ Не скрывает своё присутствие на сайте от владельца.
- ❌ Не даёт автору проекта доступ к вашему сайту или данным.
- ❌ Не отправляет никакую информацию на сторонние серверы.
- ❌ Не предназначено для клоакинга, маскировки контента от поисковых
  ботов или обмана посетителей.
- ❌ Не защищает от настоящих сетевых DDoS-атак с тысячами уникальных IP
  (для этого нужны решения уровня CDN/сети).

Это обычный, честный инструмент — устанавливайте его только на сайты,
которыми вы владеете или управляете с явного согласия владельца.

## Возможности

| Функция | Описание |
|---|---|
| 🚦 Rate limiting по IP | Настраиваемый лимит запросов за интервал времени |
| ⛔ Автоблокировка | IP, превысивший лимит, блокируется автоматически |
| 🖐 Ручная блокировка | Добавление/снятие блокировки конкретного IP через панель |
| ✅ Белый список | IP владельца сайта не подпадает под ограничения |
| 📊 Логи посещений | IP, User-Agent, URI, с автоочисткой старых записей |
| 🔐 Безопасный логин | Пароль хранится только как хеш (`password_hash`) |
| 🛡 CSRF-защита | Все формы панели защищены токенами |

- Возможность создавать файлы в корне сайта (для `db.php`, `asitee.php`, `asitee_view.php`)

## Установка

> ⚠️ Устанавливайте только на сайты, которыми вы владеете или управляете
> с явного разрешения владельца.

1. Скачайте `install.php` из [репозитория](../../) или последнего
   [релиза](../../releases).
2. Загрузите файл в корень вашего сайта по FTP/SSH.
3. Откройте `https://ваш-сайт.ru/install.php` в браузере.
4. Заполните форму:
   - хост, имя БД, пользователь и пароль MySQL;
   - пароль администратора панели (минимум 8 символов);
   - ваш IP (будет добавлен в белый список);
   - лимит запросов и окно времени (по умолчанию 100 запросов / 60 сек).
5. После нажатия «Установить» скрипт создаст:
   - `db.php` — настройки подключения к БД;
   - `asitee.php` — защитное ядро;
   - `asitee_view.php` — панель управления.
6. **Удалите `install.php`** — он больше не нужен и не должен оставаться
   на сервере.
7. Подключите защиту, добавив в самое начало точки входа сайта
   (например, `index.php`):
   ```php
   require_once __DIR__ . '/asitee.php';
   ```
   Если у сайта несколько точек входа — добавьте строку в каждую, либо
   используйте `auto_prepend_file` в конфигурации PHP (`php.ini` или
   `.htaccess`):
   ```apache
   php_value auto_prepend_file "/полный/путь/до/asitee.php"
   ```

## Использование

Откройте `https://ваш-сайт.ru/asitee_view.php` и войдите с паролем,
указанным при установке. В панели доступно:

- общее число запросов за сегодня;
- настройка лимита и окна времени;
- список заблокированных IP с возможностью разблокировки;
- топ-20 самых активных IP за последние 24 часа;
- ручная блокировка произвольного IP.

## Как это работает

При каждом запросе к сайту `asitee.php`:

1. Проверяет, не находится ли IP в чёрном списке (`asitee_blocked`) —
   если да, отдаёт `HTTP 429` и завершает выполнение.
2. Пропускает без ограничений IP, указанный как администратор.
3. Логирует визит (IP, User-Agent, URI) в `asitee_logs`.
4. Считает число запросов с этого IP за последние N секунд.
5. Если число превышает лимит — добавляет IP в чёрный список и
   отдаёт `HTTP 429`.
6. С вероятностью ~1% на запрос удаляет логи старше 2 дней (простая
   самоочистка без cron).

Всё хранится в вашей собственной базе данных, никаких внешних вызовов.

## Настройка под reverse-proxy / CDN

По умолчанию IP определяется через `$_SERVER['REMOTE_ADDR']`. Если сайт
работает за Cloudflare, nginx-прокси или другим CDN, все посетители
будут выглядеть так, будто заходят с одного IP (IP самого прокси).

Откройте `asitee.php` и измените функцию `asitee_client_ip()`,
например для Cloudflare:

```php
function asitee_client_ip(): string {
    return $_SERVER['HTTP_CF_CONNECTING_IP']
        ?? $_SERVER['REMOTE_ADDR']
        ?? '0.0.0.0';
}
```

⚠️ Никогда не доверяйте `X-Forwarded-For` напрямую без проверки, что
запрос действительно пришёл от вашего доверенного прокси — иначе
атакующий сможет подделать этот заголовок и обойти блокировку.

## Структура базы данных

```
asitee_logs      — журнал визитов (ip_address, user_agent, request_uri, visit_time)
asitee_blocked   — заблокированные IP (ip_address, reason, blocked_at)
asitee_settings  — настройки (admin_pass_hash, admin_ip, threshold_count, threshold_window)
```

## Ограничения

- Это защита уровня приложения, а не сети. Против настоящей
  распределённой DDoS-атаки с тысячами уникальных IP она бессильна —
  для этого нужны решения уровня CDN (Cloudflare, DDoS-Guard и т.п.).
  Asitee эффективен против отдельных агрессивных ботов/скриптов с
  одного или небольшого числа IP.
- Нет встроенной поддержки IPv6-подсетей (блокировка идёт по точному
  адресу, а не по CIDR-диапазону).
- Панель `asitee_view.php` стоит дополнительно закрыть на уровне
  веб-сервера (например, ограничить по IP через `.htaccess`).

## FAQ

**Можно ли ставить на чужой сайт без спроса?**
Нет. Устанавливайте только там, где у вас есть право это делать.

**Собирает ли скрипт данные на внешний сервер?**
Нет. Все данные хранятся исключительно в вашей базе данных.

**Защитит ли это от серьёзного DDoS?**
От объёмной сетевой атаки — нет. От назойливого бота/парсера,
долбящего сайт с одного-двух IP — да.

**Как изменить лимит после установки?**
Через панель `asitee_view.php` → «Настройки лимита».

**Что делать, если я случайно заблокировал себя?**
Зайдите в БД напрямую (phpMyAdmin/консоль) и удалите свою запись из
таблицы `asitee_blocked`, либо обновите `admin_ip` в `asitee_settings`.

## Безопасность

Пароль администратора хранится только в виде хеша (`password_hash`,
алгоритм по умолчанию PHP). Все формы панели защищены CSRF-токенами.
Подробности и порядок сообщения об уязвимостях — в [SECURITY.md](SECURITY.md).
