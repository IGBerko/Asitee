# Как внести вклад

Спасибо за интерес к проекту!

1. Форкните репозиторий.
2. Создайте ветку под свою правку: `git checkout -b fix/my-fix`.
3. Внесите изменения. Пожалуйста, добавляйте комментарий в код с
   указанием, что и зачем изменено (это требование лицензии IPL 2.0
   при распространении производных версий).
4. Откройте Pull Request с описанием проблемы и решения.

## Правила

- Не добавляйте функциональность, скрывающую поведение скрипта от
  владельца сайта, на котором он установлен.
- Не добавляйте отправку данных на внешние серверы без явного,
  document­ированного согласия администратора сайта.
- PHP-код должен работать без предупреждений на PHP 8.0+.
